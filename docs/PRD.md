# 产品需求

本地中文多智能体圆桌：创建话题 → 动态阵容 → 模型分配 → 用户确认 → 专家参与与主持 → 实时共识分歧 → 自然语言总结。

硬性要求：前后端分离、SQLite、默认四专家与一主持人、专家基于同一公开历史自主选择参与、1–2 句短发言、动态洞察带证据、并行隔离、实时同步、中文响应式和独立滚动。仅公开状态与正式消息。

已选默认：2–6 专家、16 次专家发言、主持开场/追问最多 4 次、最近 12 条上下文、每 3 条专家发言更新洞察、3 场并行、全局调用并发 4、连接并发 2。深色三栏演播厅，手机页签。

新增需求：网页管理多服务商 API 连接；每位专家分别绑定可复用连接；主持人连接默认承担后台任务；执行前冻结连接版本。讨论前可修改主持人连接，阵容生成使用创建时选择的默认连接。

首版不含账号、云部署、联网检索、语音视频、时间轴回放或固定专家库。历史样例明确标识，不模拟真实在线调用。真实 API 验证以用户提供的连接为前提。

交付过程采用逐项验收：见 tasks.md 与 verification.md，失败检查修复后再继续。
